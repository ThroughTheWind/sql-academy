# Operations Track

The operations track turns the repository into a production-oriented training environment rather than a pure query workbook.

Start in [Learning Docs](../learning/README.md) if you want the recommended order rather than an operations reference page.

Core topics:
- environment bootstrap and reproducibility
- migrations and release safety
- telemetry, logging, and metrics review
- incident-style debugging scenarios
- blocking and deadlock triage
- rollback strategy and change audit discipline
