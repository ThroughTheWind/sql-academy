# Expected Outcomes

- the learner keeps at least one workload in `SqlAcademy.Worker` because it depends on app-hosted configuration or observability
- the learner identifies that a release preflight gate is not automatically a good blind recurring SQL Server Agent job
- the chosen scheduled workload includes an overlap or idempotency rule plus a post-run validation check
- the answer treats failure visibility as part of job safety rather than as an afterthought
